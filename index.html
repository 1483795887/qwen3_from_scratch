01 · Runtime

运行时架构

从 User prompt 到 GPU CUDA kernel 的完整链路。Host 侧负责调度、批处理和显存分配；Device 侧执行模型前向和 Triton 算子。

02 · What's Inside

三层核心实现

模型结构、CUDA 算子、推理引擎，三个层次都自己写一遍。

MODEL · 模型架构

完整实现 Qwen3 结构，模块化设计，可通过 ComponentFactory 切换不同实现。

  • Embedding + Transformer Blocks + RMS Norm
  • RoPE 旋转位置编码
  • MLP with SwiGLU
  • 支持加载 HuggingFace 预训练权重

KERNELS · CUDA / Triton 算子

手写高性能 GPU 算子，减少显存访问和 kernel launch 开销。

  • RMS Norm 融合算子
  • PagedAttention Triton 实现
  • Fused RMSNorm + Linear
  • KV Cache 写回算子

ENGINE · 推理引擎

PagedAttention 显存管理 + CUDA Graph 加速 + 混合 batch 调度。

  • FCFS 调度 + Watermark 水位限制
  • Chunked Prefill + 请求抢占
  • Prefix Cache 跨请求 KV 共享
  • CUDA Graph Capture / Replay

04 · Get Started

快速上手

三步跑起来：装依赖 → 编译算子 → 加载模型。

# 使用 uv 管理依赖
uv sync --index-url https://pypi.tuna.tsinghua.edu.cn/simple
uv pip install -e .

# 下载模型权重到本地
# 编辑 .env 设置 MODEL_PATH
cmake -B build
cmake --build build

# 编译完成后，kernels/ 下会生成 ops 动态链接库
from qwen3_from_scratch.kernels import ops
from qwen3_from_scratch.inference.llm.llm import LLM

llm = LLM("config.yaml", "qwen3-0.6b")
llm.warmup()

print(llm.generate("你好"))
